### Задание 1

-a Архивный режим — сохраняет атрибуты, права, временные метки и рекурсивно копирует всё
-v Выводит подробную информацию о процессе
-h Человеко-понятный вывод размеров файлов
-c Принудительно сравнивает файлы по контрольным суммам (хэшам)
--delete Удаляет файлы из приёмника, которых нет в источнике (зеркалирование)
--exclude='.*/' Исключает все скрытые папки
